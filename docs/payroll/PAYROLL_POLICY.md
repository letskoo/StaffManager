# Staff Manager 급여 계산 정책

> 이 문서는 Staff Manager 급여 계산의 기준 문서(Source of Truth)다.
>
> 급여 계산 코드는 이 문서에 정의된 정책을 기준으로 구현한다.
> 계산 방식 변경 시 코드를 먼저 수정하지 않고,
> 이 문서를 먼저 수정한 후 코드에 반영한다.

---

# 1. 기본 원칙

Staff Manager는 사업장마다 근무요일, 근무시간, 휴게시간,
급여 방식이 다를 수 있다는 것을 전제로 한다.

따라서 모든 월급제 직원에게 동일한 월 환산시간을
고정 적용하지 않는다.

직원 등록 시 설정된 근무요일, 근무시간, 휴게시간,
급여 정책을 기준으로 급여를 계산한다.

---

# 2. 급여 유형

Staff Manager는 급여 유형을 다음과 같이 구분한다.

## 2.1 월급제

직원에게 설정된 월 급여를 기준으로 계산한다.

정상적으로 근무한 경우 계약된 월급 전액을 지급한다.

계약상 휴무일인 토요일, 일요일 등이 있다는 이유만으로
월급을 차감하지 않는다.

유급으로 처리되는 휴일 역시 해당 법령과
사업장 정책에 따라 급여에 반영한다.

## 2.2 시급제

실제 급여 인정 근무시간을 기준으로 계산한다.

주휴수당, 연장근무, 야간근무, 휴일근무 등은
각 정책의 적용 조건에 따라 별도로 계산한다.

---

# 3. 월급제 일할계산

## 3.1 기본 방식 — 역일수 방식

Staff Manager의 기본 월급 일할계산 방식은
해당 월의 전체 역일수를 사용하는 방식으로 한다.

계산식:

월 일급 = 월급 ÷ 해당 월의 전체 날짜 수

예:

- 2월: 28일
- 윤년 2월: 29일
- 3월: 31일
- 4월: 30일
- 9월: 30일

예시:

월급 5,000,000원
2026년 9월

5,000,000 ÷ 30
= 166,666.666...원

계산 과정에서는 소수점을 유지하고,
최종 급여 산출 단계에서 정해진 반올림/절사 정책을 적용한다.

상태: 기본 정책 확정

# 4. 월급제 일할계산 방식 확장 계획

향후 직원 등록 또는 급여 정책 설정에서
월급제 일할계산 방식을 선택할 수 있도록 확장한다.

## 방식 A — 역일수 방식

기본값.

월급 ÷ 해당 월 전체 날짜 수

## 방식 B — 소정근로일 + 유급처리일 방식

향후 추가 예정.

해당 월의 소정근로일과 유급으로 처리되는 날을 기준으로
월급 일할금액을 계산한다.

정확한 계산 범위와 유급일 포함 조건은
구현 전에 법적 기준과 사업장 설정 방식을 추가 검토한다.

상태: 향후 구현

# 5. 월급제 시간단가

## 5.1 209시간 고정 사용 금지

Staff Manager에서는 모든 월급제 직원의
급여 계산에 209시간을 일괄 적용하지 않는다.

209시간은 특정 근로조건에서 통상임금 또는
최저임금 등의 시간급 환산에 사용될 수 있는 기준시간이며,
모든 사업장의 모든 월급제 직원에게 동일하게 적용되는
실제 근무시간을 의미하지 않는다.

따라서 다음과 같은 일반 급여 계산에

월급 ÷ 209

공식을 고정 적용하지 않는다.

- 지각
- 조기퇴근
- 휴게시간 초과
- 부분근무
- 기타 실제 근무시간에 따른 월급 조정

직원의 근무요일, 근무시간, 휴게시간과
Staff Manager의 월급제 일할계산 정책을 이용하여
실제 시간단가를 계산한다.

상태: 수정 필요

# 6. 월급제 부분근무 계산

지각, 조기퇴근, 휴게시간 초과 등이 발생한 날에는
해당 날짜의 일급과 정상 급여 인정시간을 기준으로 계산한다.

기본 구조:

1. 해당 월의 일급 계산
2. 해당 날짜의 정상 급여 인정시간 계산
3. 실제 급여 인정 근무시간 계산
4. 실제 인정 근무시간에 해당하는 급여 계산

기본 계산식:

월 일급
= 월급 ÷ 해당 월 전체 날짜 수

정상 분당급여
= 해당 날짜 일급 ÷ 해당 날짜 정상 급여 인정시간(분)

해당 날짜 인정급여
= 정상 분당급여 × 실제 급여 인정 근무시간(분)

세부적인 휴게시간 처리와 각 승인정책의 적용 순서는
실제 테스트를 통해 계속 검증한다.

상태: 검증 중

# 7. 승인 정책 기본 원칙

승인은 해당 출결 이벤트를 실제 급여 조정 사유로 인정한다는 의미다.

거절은 해당 이벤트를 급여 조정 사유로 인정하지 않고
정상 근무로 처리한다.

현재 기본 정책:

- 지각 승인 → 지각시간 급여 미인정
- 지각 거절 → 정상 출근 인정
- 조기퇴근 승인 → 조기퇴근시간 급여 미인정
- 조기퇴근 거절 → 정상 퇴근 인정
- 휴게시간 초과 승인 → 초과 휴게시간 급여 미인정
- 휴게시간 초과 거절 → 정상 휴게 인정
- 결근 승인 → 실제 결근으로 인정
- 결근 거절 → 정상 근무 인정
- 조기출근 승인 → 승인된 조기근무시간 급여 인정
- 연장근무 승인 → 승인된 연장근무 급여 지급
- 야간근무 승인 → 적용 조건 충족 시 야간가산 지급

각 정책의 정확한 계산식은 테스트를 통해 검증한다.

---

# 8. 계산 검증 원칙

급여 계산 오류가 발견되면 다음 순서로 처리한다.

정책 확인
→ 수동 계산
→ 실제 프로그램 결과 비교
→ 원인 확인
→ 정책 문서 수정
→ 코드 수정
→ 동일 조건 재테스트

한 정책을 수정할 때 다른 급여 정책의 계산 결과가
변하지 않는지도 함께 확인한다.
